## Critical Aesthetic Direction (2026-03-11)
The brand explicitly rejects AI image tells. Core rule: prompts should read like a photographer's brief, not an AI render spec.

**Banned language:** "8K", "hyperrealistic", "photorealistic rendering", "ultra-detailed", "sharp focus on every surface", "studio lighting", "professional photography"

**Required language:** "shot on Kodak Portra 400", "35mm film", "Fuji 400H", "candid editorial", "available light only", "natural vignette", "slight grain", "unstaged", "imperfect", "caught mid-moment"

**Props rule:** Props are incidental scene evidence, not featured objects. Never name a prop prominently in a prompt — AI over-renders named props as hero subjects. Keep prop references ambient and subordinate to the human subject.
